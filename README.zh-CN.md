# design-redline（设计红线）

[English](./README.md) · **简体中文**

> 把"感觉哪里不对，又说不清"变成一份可排序、可落地修复的设计红线清单。

**design-redline** 是一个用来*评审*界面、而非构建界面的 agent 技能。把你的编码 agent 对准一张截图、一个线上
URL、一个 Figma 画板或一个组件，它会用十个评审视角审视设计，能量化的就量化，并交回一份报告——其中每条问题都按
**阻断 / 严重 / 次要 / 打磨**分级，并写成*现象 → 为什么重要 → 具体怎么改 → 如何验证*。它是你工作流里"设计评审"
的那一半：无论你用什么来构建，它都能搭配。

大多数设计反馈都死在"品味"这一步——"做得更抓眼一点""感觉太挤了"——而创作者无法对着一种感觉动手。这个技能把
感觉翻译成一份你可以逐条处理、逐条打勾的清单。

## 它有何不同

- **先测量，再评判。** 一个间距不是"太紧"，而是"8px，而它的同级都是 16px"。对比度不是"有点浅"，而是
  "3.1:1，而 WCAG AA 需要 4.5:1"。
- **每条问题都欠一个修复方案。** 没有一条问题会在缺少"一个具体、可落地的改动 + 一个验证方法"的情况下进入报告。
- **先讲级别，别先列清单。** 它以结论和那一个最要紧的修复开头，这样你不会在四十条等权重的意见里淹没，而真正的
  阻断却还活着。
- **只评审，不重做。** 它尊重你所构建的东西，并精确告诉你该改什么——适用于任何技术栈（HTML/CSS、React、Vue、
  Svelte、SwiftUI、原生）。

## 功能特性

- **十个评审视角** —— 视觉层级与焦点、布局与对齐、间距与节奏、字体排印、色彩与对比度、状态与边界情况、
  动效与反馈、文案与微文案、无障碍、响应式。
- **五秒第一印象测试** —— 在细节让你盲目之前，先抓住视觉层级的失败。
- **严重性分级** —— 阻断 / 严重 / 次要 / 打磨，依据是对界面真实本职的影响。
- **一个 WCAG 2.2 对比度检查器**（`scripts/contrast.py`）—— 支持单对颜色或 CSV 批量，给出 AA/AAA 及
  非文本（UI 组件）判定，无任何依赖。
- **状态与边界情况覆盖** —— 悬停、聚焦、禁用、加载、空、错误、成功、溢出。
- **一份现成的报告模板**，让每次评审都以同一种、可快速浏览的结构返回。
- **完整的英文与中文版本**（技能与文档）。

## 安装

克隆仓库，然后把技能接入你的 agent。

```bash
git clone https://github.com/fangdididi/design-redline.git
```

### Claude Code
把技能复制到你的 skills 目录（项目级或用户级）：

```bash
mkdir -p .claude/skills/design-redline
cp -r design-redline/* .claude/skills/design-redline/
```

Claude Code 会自动发现它；让它"评审"或"红线标注"一个界面即可，或按名称调用技能。

### Codex
把文件夹放到 Codex 配置加载 skills/指令的位置（例如它会读取的 `skills/` 目录），并在你的提示里引用
`SKILL.md`，或把技能内容粘贴进 `AGENTS.md` / 项目指令。

### Cursor
把它作为项目规则或技能加入：把文件夹放进你的仓库并引用 `SKILL.md`，或把其指引粘贴进 `.cursor/rules`。
然后让 Cursor 评审一张截图或一个运行中的页面。

### 其他任意 agent
`SKILL.md` 是带 YAML frontmatter 的纯 Markdown。把它交给任何能读取指令的 agent，并用 Python 3 运行辅助脚本即可。

## 使用方法

把产物和界面意图一起交给 agent：

```
用 design-redline 评审这个注册界面。它面向用手机的初次访客；唯一重要的动作是"创建账号"。这是 URL / 截图。
```

agent 会框定评审、在 360/768/1280px 采集证据、做五秒测试、走一遍十个视角、给每个发现评级，并返回一份 `redline.md`。

### 对比度辅助脚本

```bash
# 单对颜色
python3 scripts/contrast.py "#E57373" "#FFFFFF"

# 大号文字（>=24px，或加粗 >=19px）
python3 scripts/contrast.py "#767676" white --size 24

# 批量：CSV 每行为  fg,bg[,label]
python3 scripts/contrast.py --pairs pairs.csv
```

它会打印对比度，并对正文（AA 4.5:1 / AAA 7:1）、大号文字（AA 3:1 / AAA 4.5:1）、UI 组件与图形（AA 3:1）
分别给出 PASS/FAIL。当某一对未通过正文 AA 时退出码非零，因此你可以用它来卡住构建。

## 示例

**之前：** "注册页感觉哪里不对，而且有点难读。"

**之后（红线节选）：**

```
结论：暂不可上线。核心动作输给了更响亮的"了解更多"链接，且密码错误提示读不清。1 阻断，2 严重，3 次要，2 打磨。

[阻断] 色彩与对比度 · 行内密码错误文字
现象：错误文字 #E57373 在 #FFFFFF 上实测 2.9:1；AA 需要 4.5:1。
为什么重要：最需要看到这条错误的用户，恰恰最不可能读到它，并可能就此放弃注册。
修复：加深到 #C62828（白底上 5.6:1），并加一个非颜色线索（前置"!"图标 + 加粗标签）。
验证：对这一对颜色重跑 scripts/contrast.py，确认 >=4.5:1；去掉颜色后图标仍可辨。
```
